# Facet 范围声明（SCOPE）

> 版本：v1.0.0 ｜ 状态：生效 ｜ 依据：对 Typora 1.12.3（Electron 35.6.0）的 REA 静态逆向
>
> 本文件是 Facet 的唯一范围基准。任何功能增减必须先改这里，再进代码。

## 1. 项目定位

Facet 是一个**个人使用的 Markdown 工作台**，通过逆向工程研究 Typora 的功能面后重新设计实现。
核心设计支点来自逆向发现的结构：Typora 内部存在一条完整的
`Markdown ⇄ AST ⇄ HTML` 双向管线（`19` 解析 / `13` 节点定义 / `12` 回写 / `14` 输出），
但 Typora 把这层关进了黑盒。Facet 的决定是**把 AST 外化为一等公民**：

- 三态同屏：源码 / AST / 渲染，节点 ID 双向绑定；
- AST 作为唯一中间表示（IR），导出格式 = 更换一个 renderer；
- 反向链接与文档图谱（Typora 的大纲 `44` 与文件搜索 `45` 在内部从不相连，Facet 把它们拼起来）。

## 3. Facet 新增（反推设计支点）

| 能力 | 说明 |
|---|---|
| AST 三等公民 | 右栏语法树可展开，点击节点 → 渲染区高亮 + 源码区选中对应行；反向亦然 |
| 节点 ID 映射 | 解析产物带稳定 id 与行号，三态联动的锚点 |
| 反向链接 | `[[Wiki 链接]]` 入链/出链面板，附带上下文行 |
| 快照时间轴 | 每次停顿自动留存，可按时间回滚 |
| AST JSON 导出 | 把中间表示本身作为交付格式 |

## 4. 明确排除（不做，且不计划做）

以下均在逆向 Typora 时发现，但**Facet 明确不实现**：

| 排除项 | 原因 |
|---|---|
| 许可激活 / 反盗版 / 机器指纹 / RSA 校验 / 设备数上限 / 试用倒计时 | **个人使用，不需要。** 逆向仅为理解功能面，不复制其授权体系 |
| 遥测 / 崩溃上报上传 | 个人使用，无数据收集 |
| 自动更新器 | 个人使用，手动更新 |
| 云图床 / S3 / PicGo / PicList 上传 | 本地优先，不上传任何数据 |
| 账号系统 / 多端同步 | 本地单机 |
| pandoc 外部格式转换（docx/epub/opml/textile） | 引入外部进程依赖，违背"零依赖单文件"目标；如确有需要以后以独立插件形式评估 |

## 5. 质量基线（不可妥协）

1. **CommonMark 0.31.2 规范 652 个用例**：目标 100% 通过，真实通过率记录在 `docs/TESTING.md`，不谎报。
2. 单元测试覆盖扩展语法（表格/数学/wiki链/脚注/任务列表）。
3. 构建产物必须可从 `file://` 直接打开，零网络请求。
4. 任何提交不得降低测试通过率。

## 6. 范围变更流程

1. 在 `docs/SCOPE.md` 登记变更（增/删/移）。
2. 同步更新 `CHANGELOG.md`（Unreleased 段）。
3. 代码实现后更新本文档状态列。
